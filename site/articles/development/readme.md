# Development

CodexGui.Markdown is a .NET 10 repository containing the core Markdown library, optional plugins, a sample, and tests.

## Core validation path

- build the solution
- run the headless test suite
- pack the library projects
- regenerate and validate the Lunet documentation site

Continue with [Build, Test, and Docs](build-test-and-docs/) for exact commands.
