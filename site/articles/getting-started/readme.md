# Getting Started

CodexGui.Markdown is a .NET 10 solution containing reusable Avalonia Markdown libraries and a standalone sample.

## Fast path

1. Install the .NET 10 SDK.
2. Build and test `CodexGui.slnx`.
3. Run `src/CodexGui.Markdown.Sample`.
4. Explore the core library and optional plugin projects under `src/`.

Continue with the [overview](overview/) or go directly to [running the sample](running-the-app/).
