# Documentation

Use ProMarkdown to render, edit, inspect, and extend Markdown in Avalonia applications. The documentation is organized around application tasks first, with contributor material kept in a separate development section.

## Read by intent

- Start with [Getting Started](getting-started/) to install the packages and render your first document.
- Use the [User Guide](markdown/) for controls, rendering, editing, themes, source mapping, and optional features.
- Open [Reference](reference/) for the public API and package-by-package reference.
- Use [Development](development/) only when contributing to ProMarkdown itself.
