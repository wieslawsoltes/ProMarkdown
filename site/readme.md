## Included capabilities

<div class="pm-highlight-grid">
  <div class="pm-highlight-card">
    <strong>Rendering and layout</strong>
    <p>Markdig-based parsing, Avalonia document composition, themes, hit testing, selection, and source mapping.</p>
  </div>
  <div class="pm-highlight-card">
    <strong>Editing services</strong>
    <p>Source-aware editing helpers and editor plugins for structured Markdown elements.</p>
  </div>
  <div class="pm-highlight-card">
    <strong>Optional plugins</strong>
    <p>Alerts, containers, definition lists, figures, footers, math, Mermaid, syntax highlighting, and TextMate integration.</p>
  </div>
  <div class="pm-highlight-card">
    <strong>Runnable sample</strong>
    <p>A standalone Avalonia application demonstrates the complete library and plugin stack.</p>
  </div>
</div>
