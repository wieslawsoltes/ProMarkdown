    Extending ProMarkdown

    ProMarkdown separates extension responsibilities into parser, block-renderer, inline-renderer, editor, and block-template contracts. An IMarkdownPlugin registers any combination of these capabilities through MarkdownPluginRegistry.

    Use the extension APIs when an application needs syntax, native Avalonia visuals, editor experiences, or insertion templates that do not belong in the core library.

    Extension paths

    • Plugin Model and Registration explains composition, ordering, and service setup.
    • Parser Plugins configure Markdig or transform source before parsing.
    • Rendering Plugins turn AST nodes into native Avalonia text or controls.
    • Editor Plugins resolve source-mapped nodes and commit source replacements.
    • Block Templates add reusable insertion choices to editor surfaces.

    The complete contract signatures are listed in the API Reference.
